# CLAUDE.md — rules for working on this book

Read STATUS.md first. At the end of every task: update STATUS.md (and this file if a rule changed), commit, pull --rebase, push.

## Efficiency
- Brian wants Claude usage kept low. Prefer text/data work over browser work; avoid screenshot-heavy loops.
- Try format changes on 1–2 sample pages before rebuilding all ~350 pages.
- Deliver drafts as PDF (Letter, portrait). He edits in Google Docs, not Word; spreadsheets go to Google Sheets — but he does NOT want to maintain building data in a spreadsheet: Claude decides tenant/use.

## Content rules (set by Brian)
- Order: street chapters north→south, buildings west→east within each street. One page per building.
- Conjuntos: neighbouring buildings forming a conjunto are listed under the main listed house, each with its own data block below (e.g. Puebla 109 = Orizaba 27, one house with two addresses, with Orizaba 25 & 23 A).
- Title line: "Address (Name type)" only when the tenant matters to a passerby and has renown (renowned restaurant, hotel, museum, notable venue), e.g. "Colima 256 (Huset restaurant)". Offices, clinics, mixed use stay off. Never "Michelin" in the title — Michelin distinctions go on the Current-use line.
- Dominant tenant is judged from Google Maps "At this place" (review counts as a proxy for renown).
- Source passages: the working draft keeps them translated into English IN FULL with page numbers / Kindle locations; they will be rewritten later to avoid plagiarism. Source goes in a footnote.
- Never attribute one building's source description to another building's photo (no callouts across buildings).
- Photos: Google Maps Street View screenshots only, as a guide for Brian's own later photos. NO Mapillary. If a vehicle blocks the façade, try an earlier year.
- A Street View shot is valid only if the address label Google shows on it matches the building's street and number (within a few numbers), or the cross street for a corner building. Never use a shot from blocks away.
- Street View caption links to the exact panorama (or the address search); every "Google Maps" mention is a real link.
- Demolished buildings go in regular street order (marked †, unnumbered), showing Street View of what stands on the lot now, with built / architect / lost / on-the-site-now and the source passage.
- Churches are excluded.
